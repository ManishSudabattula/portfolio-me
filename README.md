# Manish Sudabattula — Portfolio

A recruiter-focused supply chain analyst portfolio built with HTML, CSS, and lightweight JavaScript. Palette: cream #F6EFD2, khaki #E2DDB4, black #000000, red #E43636.

## Content

Experience at FedEx and Next Shippment LLP, resume-backed professional work highlights, skills, education, and contact links. Graphics are illustrative; metrics are reported in the supplied resume, not live dashboard data.

## Preview

Run `python -m http.server 8010` from this directory and open http://127.0.0.1:8010/.

No installation, build step, backend, credentials, or external fonts are required. Relative paths support GitHub Pages at /portfolio-me/. Retain the existing Pages configuration.

## Accessibility

Semantic navigation, skip link, visible focus, responsive layouts, and reduced motion. Essential content works without JavaScript. The character stays still with reduced motion enabled and on touch devices.

## Assets

- assets/manish-character.png: transparent editorial illustration generated from the supplied photo using the built-in image generation tool. Brief: recognizable wavy hair, beard, red shirt, cream notebook; black outlines and restrained shading, isolated on transparency.
- assets/manish-sudabattula-resume.docx: unmodified original resume download, including its author-provided contact details. Visible web copy omits the phone number and uses sudabattulam26@gmail.com.

## Features

Unified sans-serif metadata, sticky active-section navigation, reading progress, links from results to supporting work, keyboard-accessible native experience disclosures, and a skill-to-impact explorer. Email copying is available on secure browsers with clipboard support and reports failures clearly.

The character uses gentle floating motion and pointer tilt. Touch devices and reduced-motion settings keep the character still.
