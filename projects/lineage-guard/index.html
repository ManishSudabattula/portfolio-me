The problem

A small schema edit can silently break dashboards, features, and downstream contracts. OpenLineage provides the dependency primitives; LineageGuard turns them into a pre-deployment decision with owners, severity, and a repair plan.

System design

Move reliability left.

01 / INGEST

Unify metadata

Collect schema facets, run events, ownership, SLAs, and column transformations from orchestration and warehouse systems.

02 / TRAVERSE

Compute impact

Walk downstream column dependencies and weight each asset by criticality, usage, freshness, and contract severity.

03 / REASON

Explain the change

Ground an AI copilot in the exact diff and graph so its migration plan is constrained by real dependencies.

04 / ENFORCE

Gate deployment

Post the decision to CI, require owner approval for critical assets, and verify compatibility during rollout.
