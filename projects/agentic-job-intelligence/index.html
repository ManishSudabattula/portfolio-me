Agentic Job Intelligence

A local-first AI automation system that navigates job pages, detects platform structure, extracts normalized job data with LLM assistance, persists artifacts, and creates a tamper-evident audit trail for every run.

Problem

Job pages vary by platform, authentication state, lazy-loaded content, and DOM structure. Reliable automation needs more than scraping: it needs orchestration, fallbacks, traceability, and idempotent persistence.

System walkthrough

Architecture

Production-minded agent design.

01 / ORCHESTRATION

Navigator Agent

Coordinates URL normalization, sessions, platform detection, content expansion, extraction, screenshots, and persistence.

02 / TOOL USE

Browser Layer

Playwright provides browser navigation, DOM probing, lazy loading, authentication handling, and reproducible page capture.

03 / REASONING

LLM Extraction

Claude 3.5 Sonnet via OpenRouter supplements deterministic selectors when page structure is incomplete or ambiguous.

04 / RELIABILITY

Audit + Storage

SQLite, SHA-256 artifact hashes, and hash-chained audit events create traceability, integrity checks, and idempotent persistence.
